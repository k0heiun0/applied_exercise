# 応用データ分析演習　教材

長崎大学「応用データ分析演習」（全14回）の演習ノートとデータです。
Google Colab 上で実行することを前提にしています。

データはこのリポジトリから自動で読み込まれるので、
**ダウンロードや事前準備は要りません**。

## 使い方

1. 下の表の「演習」列の **開く** をクリックすると、Colab でノートが開きます
2. Colab のメニューから **［ドライブにコピー］** を選びます（コピーしないと編集が保存されません）
3. セルを上から順に実行していきます

解答は各回の「解答」列から開けます。先に自分で解いてから見ることをすすめます。
ノートを実行せず内容だけ読みたいときは「読む」列の HTML 版をどうぞ。

## データ

演習で使うデータは `shared/data/` にあります。ノート冒頭の `DATA_DIR` が
このリポジトリの URL を指しているので、`pd.read_csv` がそのまま動きます。

収録しているのはシェアサイクルの利用実績、各国の平均寿命と経済指標、
心臓病の臨床データ、ペンギンの体格測定値、映画ジャンルの集計表です。
出典・引用文献・加工内容は **[shared/data/README.md](shared/data/README.md)**
に記載しています。再利用の際はそちらの条件を確認してください。

## このリポジトリにないもの

講義スライドと講義動画・解答動画・発展動画は、講義プラットフォームで配布します。
